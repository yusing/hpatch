# Accounting scope of this retained run

Functional grading and provider-reported usage remain valid historical evidence.
The original schema-5/metrics-v3 payload estimates tokenize serialized JSON, and the
input difference compares raw Codex carrier history against provider input after replay.
Those figures are not isolated CTP compression or stock-model token savings.

The report and measured artifacts are preserved unchanged. Current schema-6/metrics-v4
accounting uses framing-independent content estimates, the actual post-replay/native
request before CTP as its input baseline, and assistant text separately from tool-delivery
expansion. The retained sanitized counters lack those intermediate measurements, so they
cannot be repaired or relabeled; fresh captures are required for those comparisons.
